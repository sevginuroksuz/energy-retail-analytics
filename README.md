# Energy Retail Analytics

Bu repoda enerji perakende verisi uzerinden hazirlanan analiz calismasi yer almaktadir.

Proje dosyalari `case_study02/` klasoru altindadir:

- `case_study02/data/`: Ana veri dosyasi
- `case_study02/notebooks/`: Veri kesfi, gorsellestirme ve veri hikayesi notebooklari
- `case_study02/outputs/figures/`: Uretilen grafikler
- `case_study02/README.md`: Detayli proje aciklamasi

Detayli kurulum, veri yapisi ve notebook aciklamalari icin `case_study02/README.md` dosyasina bakabilirsiniz.
